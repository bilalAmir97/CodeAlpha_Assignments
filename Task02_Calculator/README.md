# Neon Calculator

A sleek, interactive calculator web application with a neon-themed design, built using HTML, CSS, and JavaScript.

## Features

- **Basic Arithmetic Operations**: Supports addition (+), subtraction (-), multiplication (×), and division (÷).
- **Decimal Support**: Allows input of decimal numbers using the dot (.) button.
- **Clear Function**: 'C' button to clear the display.
- **Equals Calculation**: '=' button to evaluate the expression and display the result.
- **Error Handling**: Displays "Error" for invalid mathematical expressions.
- **Keyboard Support**: Full keyboard input support including:
  - Numbers (0-9)
  - Operators (+, -, *, /)
  - Enter key for equals
  - 'C' or Escape key for clear
  - Backspace to delete the last character
- **Sound Toggle**: Button to mute/unmute click sounds for button presses.
- **Theme Toggle**: Switch between dark and light themes.
- **Responsive Design**: Adapts to different screen sizes, optimized for mobile and desktop.
- **Neon Aesthetic**: Features a futuristic neon design with glassmorphism effects, glowing buttons, and smooth animations.
- **Sound Effects**: Uses Web Audio API for generating click sounds on button interactions.

## How to Use

1. Open `index.html` in a web browser.
2. Use the on-screen buttons or keyboard to input numbers and operators.
3. Press '=' or Enter to calculate the result.
4. Use 'C' or Escape to clear the display.
5. Toggle sound and theme using the buttons in the top bar.

## Technologies Used

- HTML5
- CSS3 (with CSS Variables for theming)
- JavaScript (ES6+)

## Browser Compatibility

Works in modern browsers that support Web Audio API and CSS backdrop-filter.
